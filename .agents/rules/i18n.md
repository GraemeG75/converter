## Internationalization
- **Mandatory 4-Language Coverage**: Every single user-facing string in the application must be translated across all four supported locales: English (`en`), French (`fr`), German (`de`), and Spanish (`es`). No strings may be left unlocalized.
- **Zero Hardcoded Strings**: Never hardcode user-visible text in templates, components, HTML, system logs, or UI dialogs. Always use the localization engine (`t('key')`, `data-i18n`, `data-i18n-title`, etc.).
- **Key Parity**: Whenever adding, editing, or refactoring translation keys, all 4 locale dictionary files (`src/core/i18n/locales/{en,fr,de,es}.ts`) must be updated in lockstep. Never add a key to English without immediately adding the corresponding translations to French, German, and Spanish.
- **Dynamic & Parameterized Strings**: Use translation parameters and placeholders for dynamic values rather than concatenating hardcoded sentence fragments, ensuring grammatical accuracy across languages.
- **Verification**: Ensure test suites or validation checks confirm complete key parity across all four locale files.
