# Git Commit Guidelines

- **Commit Early and Often**: Do not batch multiple unrelated changes together.
- **One Item, One Commit**: Every discrete feature, bugfix, refactor, or configuration change must be its own dedicated, atomic git commit.
- **Commit Message Format**: Use standard conventional commit format with scope: `type(scope): description` (e.g., `feat(combat): ...`, `fix(map): ...`, `refactor(constants): ...`, `docs(rules): ...`, `chore(deps): ...`).
- **Atomic Commits**: Keep commits focused and well-documented with clear commit messages.
